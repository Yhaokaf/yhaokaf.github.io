CRISP药物扰动

a. 宏观流程与应用 (Fig. 1a)

这示了CRISP模型的定位和目标

  • 输入 (Inputs)：

    • 药物信息：模型可以处理来自药物数据库的药物，包括已在实验中“见过 (Seen)”的药物和“未见 (Unseen)”的新药物 。药物通过其化学结构式（SMILES字符串）输入给模型 。
    • 细胞信息：模型接收来自不同患者或实验平台的“未受扰动的细胞 (Unperturbed cells)”的基因表达谱 (Gene expr. profile) 。这些数据可以来自多种不同的测序平台（如Smart-seq, Drop-seq, 10x等），表明模型需要具备处理不同数据来源的泛化能力 。

  • 核心模型 (CRISP)：

    • CRISP模型接收细胞的基因表达谱和药物的SMILES信息，然后进行“预测 (Prediction)” 。

  • 输出 (Output)：

    • 模型的输出是预测的“受扰动后的细胞表达谱 (Perturbed profile)” 。

  • 下游应用 (Downstreams)：

    • 模型的预测结果可以用于多种生物学分析 ：

      1. 细胞类型特异性药物效应预测：通过比较预测值和真实值，评估模型对不同细胞类型药物反应的预测精度 。

      2. 将现有细胞图谱扩展到扰动空间：将预测的受扰动细胞状态进行可视化（如UMAP图），从而构建一个包含药物影响的更全面的细胞图谱 。

      3. 药物×细胞空间的功能探索：对预测结果进行通路富集分析，从生物学功能层面探索药物对特定细胞类型的影响机制 。

b. 模型详细架构 (Fig. 1b)

这部分是模型的“引擎盖”之下，展示了其内部的组件和数据流 。模型主要由两个编码模块和一个预测模块组成。

  1. 细胞类型特异性配对控制编码模块 (Cell type-specific paired control encoding module)
    • 这个模块负责处理输入的细胞基因表达 (Gene expression) 数据 。
    • 它使用一个单细胞基础模型 (Single-cell FM) 来将高维的基因表达数据编码成低维的向量 。
    • 该模块的输出是一个概率分布 N(μ,σ2)，这是典型的变分自编码器（VAE）结构，并会计算 KLD损失 (KLD loss) 来对潜空间进行正则化 。
    • 最终，从这个分布中采样得到“潜控制 (Latent control)”向量，代表了细胞在用药前的状态 。
  2. 药物扰动编码模块 (Drug perturbation encoding module)
    • 这个模块负责处理**药物（含剂量）**信息 。
    • 它使用一个化学基础模型 (Chemical FM) 来解析药物的化学结构，并结合剂量信息，将其编码成一个代表药物扰动的潜向量 。
    • 模型也可以整合其他协变量 (Other covariates)，如物种信息等，并进行编码 。
  3. 受扰动状态预测模块 (Perturbed state prediction module)
    • 潜空间融合：将“潜控制”向量、药物扰动潜向量以及其他协变量的潜向量进行融合（图中的+号），生成一个“处理后的潜向量 (Latent treated)” 。这个向量同时包含了细胞原始状态和药物作用的信息。
    • 解码与重建：
      • 解码器 D 接收“处理后的潜向量”，并将其解码，预测出受药物扰动后的基因表达谱 (“Pred.”) 。
      • 模型的预测结果会与真实的扰动后数据 (“Truth”) 进行比较，通过 MMD和MSE损失 来进行优化，目标是让预测尽可能接近真实情况 。
    • 细胞类型特异性学习机制：这是CRISP的核心创新之一，通过两个额外的任务来确保模型能区分不同细胞类型的反应：
      • 分类任务：分类器 C 同样接收“处理后的潜向量”，并预测其细胞类型。这个过程通过 交叉熵损失 (Cross-entropy loss) 进行优化，这迫使潜向量中必须包含清晰的细胞类型信息 。
      • 对比学习任务：模型中有一个“对比采样器 (Contrastive sampler)” 。它为每个样本提供一个负样本（即药物扰动相同但细胞类型不同的样本）。模型的目标是通过 余弦距离损失 (Cosine distance loss) 来“扩大 (Enlarge)”这两个样本在潜空间中的距离，从而让不同细胞类型的表征在潜空间中分得更开，增强了预测的特异性 。

总而言之，CRISP通过一个双分支的编码器结构，分别编码细胞和药物信息，然后在潜空间中融合。其解码器不仅要准确地重建出用药后的细胞状态，还要通过额外的分类和对比学习任务，来确保其预测是细胞类型特异性的。

难点理解：
输入为单细胞转录数据+药物分子数据，结合药物扰动后的单细胞转录表达数据，进行模型训练，训练得到的是此药物对不同细胞的表达影响。一开始结合scGPT+RDkit两个encoder，分别得到嵌入特征，在融合了细胞和药物信息的“处理后的潜向量 (Latent treated)”后面，额外接了一个细胞类型分类器 (Classifier, 图中模块C) 训练过程：在训练模型去预测药物反应的同时，这个分类器也被要求去完成一个附加任务：根据“处理后的潜向量”，准确地判断出当前细胞的类型是什么 。

目的和效果：

  • 这个分类任务的损失（交叉熵损失）会被加到模型的总损失中 。
  • 为了在这个附加任务上取得好成绩（即降低分类损失），模型必须在“处理后的潜向量”中保留并凸显出关于细胞类型的、清晰可辨的信息 。
  • 这样一来，这个潜向量就变得信息更丰富、结构性更强。最终负责预测基因表达的解码器（模块D）就能基于这个高质量的潜向量，做出更精准的、具有细胞类型特异性的预测。论文中提到，这使得模型能够对不同的细胞类型有更好的区分度和特异性

​ 确保了模型的核心（潜向量）始终牢记着细胞类型的关键信息，从而让它的主业——药物反应预测，做得更好、更准。

应用于空转+扰动的改进方法思考：

  • 研究现状：目前的工作都是单细胞数据+药物扰动，没有找到有空转+药物扰动方向的文章，并且这个方向的数据都没有，感觉这个方向是很前沿的。

  • 输入数据为：空间转录组数据+药物分子数据，要有能够用于训练的空转数据+药物扰动后的空转表达数据（这是主要的难点），目前没找到这个方向的文章和数据。

  • 可行性分析：CRISP解决的是“哪种细胞对药物有何反应”，而空间转录组的核心优势是揭示“细胞在其原生组织位置的基因表达状态”。

  • 主要难点：找不到能用于训练的数据集，要同时有未经过扰动的空转+经过扰动的空转数据（由于不可能是同一个切片得到的，所以还要面临批次效应等问题【原论文中对这些问题有了很好的解决方案】）

  • 具体方案：如果有数据，可以考虑尝试将原来的scGPT的encoder更换成scGPT-spatial。
