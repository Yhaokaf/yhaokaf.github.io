CellFlow：用流动匹配建模复杂扰动

文章简介

  • 标题: CellFlow - Modeling Complex Perturbations with Flow Matching
  • 作者: Dominik Klein、Jonas Simon Fleck（共同一作）（主要研究团队来自TUM（慕尼黑工大计算生物组）、Helmholtz Munich等科研机构。）
  • 发表会议/期刊：bioRxiv 预印本.
  • 年份: 2025.
  • 链接：CellFlow.

文章总览

研究目标：

学一个统一的、可泛化的生成模型，在给定任意实验条件（药物 / 基因 KO / 细胞因子 / morphogen 组合等）时，生成该条件下的单细胞表型分布，从而做 虚拟 perturbation 屏幕 和 实验设计加速。

主要有三层目标：

  1. 从有限的单细胞 perturbation 数据中学习“条件 ➜ 细胞分布”的映射
    • 输入：对照细胞 + 条件信息（perturbations、剂量/时间、样本信息）。
    • 输出：该条件下的单细胞表型分布（而不是只预测某几个 marker 或均值）。
  2. 能对“未观测条件”做生成预测（zero-shot / few-shot 条件）
    • 比如药物 / 基因组合没做过实验，但模型能利用 预训练 embedding + 组合建模 推断可能的细胞响应。
  3. 统一不同类型实验的建模框架
    • 从经典 CRISPR/药物屏幕，到 PBMC 多 donor 细胞因子屏幕，再到斑马鱼胚胎、脑类器官等复杂组织/发育系统，都用同一个 CellFlow 框架来建模。

核心创新点：

总结成 4 个关键创新：

1. 条件化 Flow Matching + Neural ODE 的表型生成框架

  • 使用 flow matching 训练条件化神经向量场，不需要每一步都完整地“解 ODE 再回传梯度”，大幅减轻计算成本。
  • 通过将 control → perturbed 看成表型空间中的“流”，模型学的是一个 条件化连续流场，可以对整个分布进行生成，而不是点对点回归。

2. 融合 OT 的细胞配对机制

  • 引入 Optimal Transport (OT) 在控制细胞和扰动细胞之间建立最优配对，使得 flow 的起点和终点成对，路径更“直、更合理”。
  • 和传统只在分布层面做匹配相比，OT 使得 flow matching 的监督信号更强，提高生成分布的精度和稳定性。

3. 通用且可组合的条件编码器（Condition Encoder）

  • 将各种 perturbations / covariates / sample covariates 统一编码为一个向量：
    • 基因/蛋白扰动：用 ESM 等蛋白语言模型 embedding。
    • 小分子药物：用分子指纹（例如 ECFP）。
    • 细胞系：用 CCLE embedding。
    • 剂量、时间：标量特征。
    • donor / batch / dataset：离散 embedding 或统计特征。
  • 利用 DeepSets 或 attention-based set aggregation，实现对“多重、无序条件集合”的 permutation-invariant 聚合。
    → 这是它能在 任意数量和组合的 perturbations 下泛化的关键。

4. 在复杂发育与组织系统中的大规模应用示范

  • 不只是做“benchmark 上比别人好一点”，而是展示了：
    • 斑马鱼胚胎发育中的基因 perturbation 预测。
    • 脑类器官中上万种 morphogen 组合的 虚拟 protocol 设计与筛选。
  • 给出一套从模型到实际实验设计的完整 pipeline（虚拟屏幕 → 候选方案 → 实验验证），把生成模型真正推向“实验设计工具”。

主要挑战与创新应对

主要面临挑战：组合空间、高维分布、跨系统泛化、可扩展性。

面临的挑战 创新应对策略
perturbation × 剂量 × 时间 × 组合 × donor / batch，条件数量指数增长，不可能全部做实验 引入统一的条件编码器（Condition Encoder）：将基因 KO / 药物 / 细胞因子 / morphogen 等，分别编码为连续向量（蛋白语言模型 embedding、分子指纹、CCLE 等），再用 DeepSets / Attention 做集合聚合，在 embedding 空间中对未观测组合进行插值与外推，实现对“未测条件”的生成预测
多 cell type、多发育阶段、多组织区室构成的单细胞分布非常复杂，简单的均值回归或线性模型无法描述整体异质性 利用 Neural ODE + Flow Matching 直接学习表型空间中从 control 分布到 perturbed 分布的 连续流场（continuous flow），是对整个位形分布的生成建模，而不是只拟合平均表达；同时配合 Optimal Transport 配对，为流场提供合理的起点-终点对，提高生成分布的精度与稳定性
实验类型多（CRISPR、drug、cytokine、morphogen、发育系统、类器官等），传统方法往往为每种任务单独设计，难以迁移与统一 设计了一个 任务无关的统一条件编码器：不同类型扰动最终都投到同一条件向量 c；同一个 条件化 Neural ODE 在多任务上共享，只通过 c 区分条件；此外，通过 sample covariates 显式建模 donor / batch / tissue / dataset 差异，支持跨数据集、跨组织的迁移与泛化
传统 CNF/score-based 模型需要频繁求解 ODE/SDE 并反向传播，计算开销巨大，不适合千万级单细胞与海量条件 采用 simulation-free Flow Matching：只在采样的中间点 (x_t, t) 回归速度向量，而无需每次完整解 ODE 来计算对数似然；配合 JAX/Flax + optax 的高效实现和大 batch 训练，使 CellFlow 能在 PBMC 大屏幕、发育系统和类器官等大规模数据上高效训练
实验条件不可穷举，如何从极大的条件空间中选出优先验证的候选 perturbation / protocol？ 将 CellFlow 作为 虚拟 perturbation 屏幕引擎：在计算机中对大量未测条件生成单细胞表型分布，并结合下游统计模型（如 LASSO、energy distance 等）筛选“既真实又新颖”的条件，从而给出 follow-up 实验的优先级排序，实际在脑类器官 morphogen 组合设计中做了完整示范
PBMC 多 donor、不同 cell line、不同实验批次产生系统性差异，如果不显式建模，会掩盖真实的 perturbation effect 条件中显式引入 sample covariates：包括 donor 特异的 control 统计、细胞系 embedding（CCLE）、实验 dataset / batch ID embedding 等，让模型区分“样本固有差异”和“扰动效应”，提高跨 donor / batch 的泛化与对比分析能力

模型架构

1. 整体结构

2. 数据与表示

  1. 单细胞表型嵌入
  • 将原始单细胞数据（如 RNA 表达矩阵）压缩到一个 d 维 latent space，得到细胞表型向量：

$$
x ∈ ℝ^d
$$

  • 控制（对照）细胞记为：

$$
x₀ ∈ ℝ^d
$$

  • 某个条件下的扰动细胞记为：

$$
x₁ ∈ ℝ^d
$$

  1. 条件向量（Condition Embedding）
  • 目标是把所有条件信息编码为一个向量：

$$
c ∈ ℝ^{d_c}
$$

  • 其中 c 由三部分组成：

$$
c = E_{perturbations}(…) + E_{covariates}(…) + E_{sample}(…)
$$

理解上可以看成三路编码，再用加和或拼接后过 MLP 得到最终 c。

3. 条件编码器（Condition Encoder）

  1. Perturbations
  • 对每一个扰动（药物 / 基因 KO / 细胞因子 / morphogen），先得到其 embedding：

$$
e_i ∈ ℝ^{d_e}, i = 1, …, N_{perturbations}
$$

  • 整个扰动集合是无序的：

$$
E = { e₁, e₂, …, e_{N_p} }
$$

  • 使用 DeepSets 聚合时，可写为：

$$
c_{pert} = ρ ( ∑_{e ∈ E} φ(e) )
$$

其中 φ 和 ρ 是小的前馈网络（MLP）。

  • 或者使用 Attention 聚合（schematic）：

$$
c_pert = MultiHeadAtt(queries = q, keys = E, values = E)
$$

  1. Perturbation Covariates
  • 如剂量 dose、时间 time 等标量，先做数值变换与标准化，然后通过一个小 MLP：

$$
z_cov = MLP_cov( [dose, time, …] )
$$

  1. Sample Covariates
  • 如 donor、cell line、tissue、batch 等，对每个离散类别给一个 embedding，再和统计特征一起送入 MLP：

$$
z_sample = MLP_sample( [emb_{donor}, emb_{cellline}, emb_{dataset}, stats_{control}, …] )
$$

  1. 最终条件向量
  • 将三路特征合并得到最终条件 embedding：

$$
c = MLP_merge( [c_pert ∥ z_cov ∥ z_sample] )
$$

其中 ∥ 表示向量拼接（concatenation）。

4. 时间编码（Time Encoding）

  • 虚时间变量：

$$
t ∈ [0, 1]
$$

  • 使用 Fourier 特征或 MLP 对时间做嵌入，得到：

$$
γ(t) ∈ ℝ^{d_t}
$$

例如（Fourier 示例）：
$$
γ(t) = [ sin(2π f₁ t), cos(2π f₁ t), …, sin(2π f_K t), cos(2π f_K t) ]
$$

5. 条件化 Neural ODE 向量场

定义一个参数化的向量场：
$$
v_θ : ℝ^d × ℝ^{d_c} × [0, 1] → ℝ^d
$$
即：
$$
v_θ(x_t, c, t) = MLP_flow( [x_t ∥ c ∥ γ(t)] )
$$

  • 这里 x_t 是在时间 t 时刻的细胞表型点（在训练中来自于 x₀ 和 x₁ 的插值）。
  • MLP_flow 是若干层宽 MLP（例如隐藏层维度 4096×3）。

6. 前向生成过程（Inference / Sampling）

给定一个对照细胞 x₀ 和一个条件向量 c，通过 ODE 积分从 t = 0 演化到 t = 1：
$$
dx_t / dt = v_θ(x_t, c, t), t ∈ [0, 1]
x_{t=0} = x₀
$$
通过数值 ODE 求解器得到终点：
$$
x₁^{pred} = x_{t=1}
$$
对一批 x₀ 执行上述过程，即可得到条件 c 下的生成细胞群体分布 { x₁^{pred} }。

7. 训练过程：OT 配对 + Flow Matching Loss

  1. OT 配对
  • 在控制和扰动细胞子集中，用 optimal transport 求解最优配对，得到配对样本：

$$
(x₀, x₁)
$$

  1. 构造中间点
  • 在 [0, 1] 上均匀采样时间 t，用线性插值构造路径上的点：

$$
x_t = (1 - t) · x₀ + t · x₁
$$

  1. 理论速度（以线性路径为例）
  • 对线性路径，其“理想速度”是常数向量：

$$
u_t(x_t) = x₁ - x₀
$$

  1. Flow Matching Loss
  • 训练目标是让预测速度 v_θ(x_t, c, t) 拟合理论速度 u_t(x_t)：

$$
L(θ) = 𝔼_{c, x₀, x₁, t} [ || v_θ(x_t, c, t) - u_t(x_t) ||² ]
$$

  1. 优化
  • 使用 Adam 等优化器更新参数 θ：

$$
θ ← θ - η · ∇_θ L(θ)
$$

这里 η 是学习率（如 5e-5）。
