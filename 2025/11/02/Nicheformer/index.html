Nicheformer：一个基于单细胞&空间模态数据的基础模型

文章简介

  • 标题: Nicheformer: a foundation model for single-cell and spatial omics
  • 作者: Alejandro Tejada-Lapuerta, Anna C. Schaar, Robert Gutgesell 等。（主要研究团队来自TUM（慕尼黑技术大学）、Helmholtz Munich等科研机构。）
  • 发表会议/期刊：Nat Methods.
  • 年份: 2025
  • 链接：Nicheformer

文章总览

研究目标：

开发能整合单细胞解离数据与空间转录组数据的基础模型，解决传统单细胞分析（如 scRNA-seq）丢失空间微环境信息、现有基础模型（如 Geneformer、CellPLM）仅依赖单一数据类型训练的局限性，具体包括：

  1. 学习具有空间感知能力的细胞表征，捕捉基因表达与细胞空间位置的关联；
  2. 设计针对空间组学的专属下游任务（如空间标签预测、空间成分预测），验证模型对空间相关任务的适配性。
  3. 实现空间信息向解离单细胞数据的转移，为非空间 scRNA-seq 数据集补充空间背景。

核心创新点：

  • 多模态数据整合的预训练范式：首次在规模达 1.1 亿细胞的 SpatialCorpus-110M 数据集（含 5706 万解离细胞 + 5383 万空间细胞）上预训练，同时覆盖人 / 鼠 2 个物种、73 种组织、4 种空间技术，突破现有模型仅依赖单一模态（解离或空间）数据的限制，能学习跨模态、跨物种的细胞统一表征。
  • 空间感知的令牌化设计：在基因令牌化过程中，不仅按基因表达水平排序生成序列，还添加（实验技术）、（数据模态）、（物种）上下文令牌，让模型可明确区分并学习不同技术、模态的特征差异，为空间相关任务提供关键信号。
  • 专属空间下游任务体系：设计空间标签预测（细胞类型 / 生态位 / 区域标签）、空间成分预测（邻域密度 / 细胞类型组成）两类任务，填补了单细胞基础模型缺乏空间专属评估标准的空白，且通过线性探测与微调双策略验证模型性能，结果更具说服力。
  • 跨模态标签转移能力：实现从空间转录组数据（如 MERFISH 小鼠脑）向解离 scRNA-seq 数据的标签转移，解决了解离数据 “无空间背景” 的核心痛点，让研究者可通过非空间数据间接获取细胞空间属性。

主要挑战与创新应对

面临的挑战 创新应对策略
1. 单细胞解离数据与空间数据的模态差异大，难以统一建模 1. 构建 SpatialCorpus-110M 数据集，统一基因令牌（20310 个，含同源 / 物种特有基因）和元数据（采用 NCBITaxon、Uberon 等标准本体）；2. 设计上下文令牌（//），让模型学习模态特异性特征
2. 空间转录组数据基因 panel 小（仅数百 - 数千个基因），易导致输入信息不足 1. 采用 “基因表达相对排序” 的令牌化策略，而非绝对表达值，减少基因数量差异的影响；2. 预训练时联合解离数据（基因 panel 大）与空间数据，通过跨模态信息互补提升模型对少基因输入的鲁棒性
3. 现有模型在空间相关任务中性能差，缺乏专属评估体系 1. 设计空间标签预测、空间成分预测两类专属下游任务；2. 对比线性探测与微调效果，验证模型表征的通用性（线性探测）与任务适配性（微调），同时与 Geneformer、CellPLM 等基线模型全面对比
4. 细胞空间位置信息难以融入预训练过程 1. 虽未直接纳入空间坐标，但通过学习空间数据中细胞的基因表达关联（如邻域细胞的共表达模式），间接捕捉空间上下文；2. 下游任务中定义 “距离依赖的细胞邻域”，让模型在微调时学习空间位置与基因表达的关联

模型架构

Nicheformer 基于 Transformer 架构构建，具体结构如下：

1️⃣ 输入层

  • 数据类型：单细胞解离 RNA-seq 数据、空间转录组数据（MERFISH/Xenium/CosMx/ISS）；
  • 输入形式：1500 长度的令牌序列（每个令牌嵌入维度为 512）, 包含：
    • 基因令牌：按 “基因相对于技术特异性非零均值的表达水平” 降序排序，仅保留非零表达基因，不足 1500 时用填充；
    • 上下文令牌：3 个固定令牌，分别标注数据的实验技术（如 MERFISH、10x）、数据模态（解离 / 空间）、物种（人 / 鼠）；
  • 基因数量：统一映射到 20310 个基因令牌（16981 个同源基因 + 3178 个人类特有基因 + 151 个小鼠特有基因）。

2️⃣ Transformer 编码器模块

含 12 个堆叠的 Transformer 编码器单元，每个单元包含：

  • 多注意力机制：16 个注意力头，可并行捕捉不同维度的基因关联与上下文信息，且对令牌进行掩码，避免无效注意力；
  • 前馈网络：隐藏层维度为 1024，采用非线性激活函数，对注意力输出进行特征转换与增强。

3️⃣ 输出层

通过 “平均基因令牌嵌入” 生成 512 维的细胞级嵌入（排除上下文令牌，避免模态偏见），该嵌入可作为下游任务（分类 / 回归）的输入。

  • 预训练阶段输出：对掩码令牌的预测结果（基因令牌或上下文令牌），用于计算掩码语言建模损失；
  • 下游任务阶段输出：
    • 分类任务（空间标签预测）：细胞类型 / 生态位 / 区域的类别概率分布（通过 Softmax 激活）；
    • 回归任务（空间成分预测）：邻域细胞密度（标量）、邻域细胞类型组成（比例向量，通过 Softmax 确保和为 1）；
    • 跨模态转移：解离细胞的空间标签（如 MERFISH 脑的细胞类型 / 生态位标签）及分类不确定性（0-1，值越小不确定性越高）。

关于此文章的一些问题：

问题 1：训练时对单细胞数据如何训练空间成分及空间标签？

Nicheformer 针对 “单细胞解离数据无原生空间信息” 的特点，并非直接对单细胞数据训练空间成分与空间标签，而是通过 “预训练整合空间信号 + 下游跨模态转移” 的两步策略，间接实现单细胞数据的空间相关任务适配，具体逻辑如下：

1. 预训练阶段：单细胞数据与空间数据联合训练，间接学习空间关联

在 SpatialCorpus-110M 预训练数据中，单细胞解离数据（5706 万个）与空间转录组数据（5383 万个）被混合输入模型联合训练，核心通过以下设计让单细胞数据间接学习空间信号：

  • 统一令牌化：单细胞数据与空间数据均按 “基因相对表达排序 + 上下文令牌（//）” 生成 1500 长度序列，其中<MODALITY=dissociated>令牌明确标注单细胞数据类型，模型在掩码语言建模（MLM）任务中，会学习 “单细胞数据的基因关联模式” 与 “空间数据的基因 - 空间关联模式” 的共性特征（如细胞类型特异性基因排序在两种模态中一致）。
  • 跨模态特征共享：预训练时，模型的 Transformer 编码器会捕捉跨模态通用的细胞表征（如免疫细胞在单细胞和解离数据中均高表达 CD45），同时通过空间数据学习 “基因表达与空间成分 / 标签的关联”（如脑皮层细胞的基因排序与 “等皮层” 区域标签相关），这些空间关联特征会被整合到模型的通用表征中，为单细胞数据后续适配空间任务奠定基础。

2. 下游任务阶段：通过 “空间→单细胞” 标签转移，实现单细胞数据的空间成分 / 标签训练

单细胞数据的空间成分（如邻域密度、邻域组成）与空间标签（如细胞类型、生态位）训练，本质是将空间数据已标注的空间信息 “转移” 到单细胞数据，而非直接训练，具体流程为：

  • 空间数据预训练模型：先用空间数据（如 MERFISH 小鼠脑，含 17 个区域、8 个生态位标签）微调模型，让模型学习 “基因表达→空间成分 / 标签” 的映射关系（如某基因排序对应 “海马区” 标签）。
  • 单细胞数据标签转移：将训练好的模型应用于单细胞解离数据（如小鼠运动皮层 scRNA-seq），模型通过预训练学到的跨模态表征，将空间数据的空间成分 / 标签映射到单细胞数据 —— 例如，根据单细胞数据的基因排序，匹配空间数据中相似基因排序对应的 “邻域组成”（如该基因排序在空间数据中对应 “ glutamatergic 神经元为主的邻域”），从而为单细胞数据分配空间成分与标签。

简言之，单细胞数据不直接参与空间成分 / 标签的 “原生训练”，而是通过预训练的跨模态表征，复用空间数据的空间信息，实现间接的空间相关任务适配。

问题 2：人类 & 小鼠的跨物种研究如何开展？

Nicheformer 通过 “基因令牌标准化 + 跨物种联合预训练 + 跨物种任务验证” 的三层设计，实现人类与小鼠的跨物种研究，具体步骤如下：

1. 基因层面：构建跨物种统一基因令牌集，解决基因匹配问题

为消除人类与小鼠的基因命名差异，研究构建了包含 “同源基因 + 物种特有基因” 的统一基因令牌库，具体流程为：

  • 同源基因匹配：使用 BioMart 工具（基于 Ensembl 数据库 release 104），将人类与小鼠的蛋白编码基因进行同源性比对，筛选出 16981 个保守同源基因（如人类 TP53 与小鼠 Trp53）。
  • 物种特有基因补充：额外纳入 3178 个人类特有基因（如人类 FOXP2）和 151 个小鼠特有基因（如小鼠 Pdx1），最终形成 20310 个统一基因令牌，所有跨物种数据均映射到该令牌库。
  • 基因表达校正：预训练时，人类与小鼠数据分别使用 “物种 + 技术” 特异性的非零均值向量校正基因表达（如人类 Xenium 数据用人类 Xenium 均值，小鼠 MERFISH 数据用小鼠 MERFISH 均值），避免物种特异性表达基线差异干扰。

2. 模型层面：跨物种数据联合预训练，学习通用细胞表征

在 SpatialCorpus-110M 预训练中，人类数据（含解离和空间）与小鼠数据被混合输入模型联合训练，核心设计包括：

  • 物种上下文令牌：输入序列中添加<ORGANISM=human>或<ORGANISM=mouse>令牌，让模型明确区分物种，学习 “物种特异性特征” 与 “跨物种通用特征”（如免疫细胞的跨物种通用基因排序，以及人类神经元的物种特有表达模式）。
  • 无偏跨物种表征：预训练的 MLM 任务中，模型需预测跨物种基因令牌（如掩码人类 FOXP2 或小鼠 Trp53），迫使模型学习同源基因的共表达模式（如人类 TP53 与小鼠 Trp53 在细胞应激反应中的相似表达关联），同时通过物种令牌区分物种特有差异。

3. 任务层面：跨物种性能验证，验证模型通用性

研究通过下游任务验证跨物种模型的有效性，具体包括：

  • 跨物种模型性能对比：分别训练 “仅人类数据”“仅小鼠数据”“人类 + 小鼠混合数据” 的三个模型，结果显示混合数据模型在对方物种的下游任务中性能显著更优（如仅人类模型在小鼠脑区域预测中 F1=0.5，混合模型 F1=0.75），且差异具有统计显著性（ANOVA+FDR 校正）。
  • 跨物种基因功能关联挖掘：模型能识别跨物种保守的基因 - 空间关联（如人类与小鼠肝 zonation 中均高表达的 CYP3A4/Cyp3a11 基因，与 “中央静脉区” 标签相关），同时发现物种特有空间特征（如人类脑 AVPV 区域的 Adgrf5 基因性别差异，在小鼠中无显著表现）。

问题 3：如何推断单细胞转录组的空间位置信息？

Nicheformer 通过 “空间数据预训练空间 - 基因关联 + 单细胞数据嵌入匹配” 的核心逻辑，间接推断单细胞转录组的空间位置信息，具体流程可分为 “预训练建模空间关联”“单细胞嵌入生成”“空间位置匹配” 三步：

第一步：预训练阶段，用空间数据建模 “基因表达→空间位置” 的关联

在 SpatialCorpus-110M 预训练中，模型通过空间数据（含明确空间坐标的 MERFISH/Xenium/CosMx 数据）学习 “基因表达模式与空间位置” 的映射关系，核心机制包括：

  • 空间成分关联学习：模型在预训练中，通过空间数据的基因排序，间接捕捉 “邻域密度”、“邻域组成” 等空间成分与基因表达的关联（如肿瘤区域高细胞密度对应特定基因排序：VEGFA 高表达、CD8 低表达）。
  • 空间标签关联学习：通过含区域 / 生态位标签的空间数据（如 MERFISH 小鼠脑的 “等皮层”“海马区” 标签），模型学习 “特定基因排序→特定空间位置标签” 的映射（如小鼠脑 glutamatergic 神经元的基因排序对应 “等皮层” 区域）。

第二步：单细胞数据处理，生成与空间数据兼容的细胞嵌入

对无空间信息的单细胞转录组数据（如 scRNA-seq），按以下步骤生成嵌入，确保与空间数据的嵌入 “可比较”：

  • 统一令牌化：单细胞数据按 “基因相对表达排序 + 上下文令牌（<MODALITY=dissociated>）” 生成 1500 长度序列，与空间数据的令牌格式完全一致。
  • 嵌入生成：通过预训练好的 Nicheformer 模型，生成单细胞数据的 512 维细胞嵌入 —— 生成时排除上下文令牌（避免模态偏见），仅对基因令牌平均池化，确保嵌入仅反映基因表达模式，与空间数据的嵌入维度、特征分布一致。

第三步：空间位置匹配，通过嵌入相似性推断单细胞空间位置

利用 “空间数据的嵌入 - 空间位置映射关系”，通过以下两种方式推断单细胞的空间位置信息：

  • 基于标签转移的位置推断：若空间数据已标注 “区域 / 生态位” 等位置相关标签（如 MERFISH 小鼠脑的 17 个区域标签），先用空间数据微调模型，建立 “嵌入→位置标签” 的分类模型；再将单细胞嵌入输入该模型，模型输出单细胞对应的位置标签（如 “等皮层”），间接推断其空间位置。例如，小鼠运动皮层 scRNA-seq 数据的 glutamatergic 神经元嵌入，与 MERFISH 数据中 “等皮层” 区域的 glutamatergic 神经元嵌入高度相似，因此推断该单细胞位于 “等皮层”。
  • 基于邻域相似性的位置推断：若空间数据提供细胞的空间坐标（如 Xenium 数据的 x/y 坐标），可计算单细胞嵌入与空间数据中每个细胞嵌入的余弦相似度，将 “相似度最高的空间细胞的坐标” 作为单细胞的推断空间位置。例如，单细胞嵌入与空间数据中 “肝门静脉区” 某细胞的嵌入相似度最高（0.92），则推断该单细胞位于肝门静脉区。
